## Cómo subir a GitHub

1. Crea un repositorio nuevo en GitHub.
2. Sube todos los archivos de esta carpeta, no subas el ZIP cerrado.
3. En GitHub entra a **Settings > Pages**.
4. En **Build and deployment**, selecciona:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Guarda y espera unos minutos.

## Importante

GitHub Pages no procesa formularios en servidor. Por eso el formulario de contacto abre WhatsApp con los datos del cliente. Si más adelante quieres guardar datos en Google Sheets, Firebase, Supabase o Netlify Forms, se puede conectar una API.
