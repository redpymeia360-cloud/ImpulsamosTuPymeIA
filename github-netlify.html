Cómo publicarlo

Usa GitHub para mostrar el repositorio y Netlify para mostrar la demo como sitio web.

Crear repositorio

Nombre recomendado: portfolio-impulsamostupymeia. Sube todos los archivos de esta carpeta.

Activar GitHub Pages

En Settings › Pages, selecciona la rama main y la carpeta raíz.

Conectar Netlify

Importa el repositorio desde GitHub. Build command vacío y publish directory: .

Agregar al CV

Coloca el enlace de Netlify como “Portafolio online” y el enlace de GitHub como “Código y demos”.

Portada recomendada para README de GitHub

Copia este texto en el archivo README.md del repositorio.

# Constanza Berríos | Portafolio TI, IA y Automatización Analista Programador con experiencia en soporte TI, desarrollo web en WordPress, automatización con IA, CRM, chatbots y soluciones digitales para empresas y PYMES. ## 🚀 Portafolio online - Demo Netlify: https://impulsamostupymeia.netlify.app - Repositorio: https://github.com/cberrios10/portfolio-impulsamostupymeia ## 💼 Servicios principales - Soporte TI remoto - Desarrollo web y WordPress - Landing pages para captación de clientes - CRM inmobiliario y comercial - Chatbots de atención 24/7 - Automatización de leads con formularios, Google Sheets, email y CRM ## 🧩 Demos funcionales incluidas - Mini CRM con leads guardados en navegador - Exportación CSV de contactos - Chatbot comercial de prueba - Calculadora de oportunidad comercial ## 🛠️ Tecnologías HTML, CSS, JavaScript, WordPress, GitHub, Netlify, Google Sheets, IA, CRM, APIs. ## 📩 Contacto Disponible para trabajo remoto, práctica profesional, proyectos freelance y colaboración con empresas.
